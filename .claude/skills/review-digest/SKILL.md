# 후기 다이제스트 (최근 글 우선 · 공통 의견 · 필수 정보)

검색은 `naver-search` 스킬의 API를 그대로 쓴다 (같은 `.env` 키). 이 스킬은 **수집 규칙 + 정리 방식**을 정한다.

```bash
D=.claude/skills/review-digest/scripts
python3 $D/review_digest.py "<검색어1>" "<검색어2>" ... [--keywords 단어1,단어2] [--must 단어1,단어2] [--save 파일.json]
```

스크립트가 자동으로 하는 일:
- blog·cafearticle을 **최신순(최대 300건) + 정확도순(100건)** 으로 수집 → 중복 링크 제거
- 기간 분류: 🟢 최근 3개월 / 🟡 3~12개월 / ⚪ 카페(API가 날짜를 안 줌) — **1년 넘은 블로그 글은 버림**
- 검색어의 핵심 단어(후기·꿀팁 같은 일반어 제외)가 **모두 들어간 글만** 남김. 필요하면 `--must`로 직접 지정
- 광고 의심 표시(체험단·원고료·협찬·할인코드 등) → 공통 단어 집계에서 제외
- `--keywords`: 단어별로 **몇 개 글**에 나오는지 + 대표 링크

## 진행 순서

1. **검색어 3~6개로 쪼개기**: 대상 + 주제 + 후기/주의/꿀팁
   - 예) `스페인 렌트카 후기`, `스페인 렌트카 주의사항`, `알함브라 예약 환불`, `알함브라 티켓 후기`
2. **확인 키워드 정하기**(`--keywords`): 필수 정보가 숨어 있을 만한 단어
   - 돈/규정: `환불,취소,불가,위약금,수수료,보증금,과태료,벌금`
   - 예약: `매진,오픈,여권,실명,시간,입장`
   - 렌트카: `오토,자동,수동,풀커버,보험,국제운전면허,통행제한,주차,견인,주유`
3. 스크립트 실행 → 결과의 **반복 단어·키워드 카운트**로 공통 주제를 고른다.
4. **근거 확인**: 필수 정보로 쓸 내용은 요약문(description)만 보고 단정하지 말 것. 대표 글 3~5개는 web-fetch 에이전트로 본문을 읽어 확인한다 (`blog.naver.com/아이디/글번호` → `m.blog.naver.com/아이디/글번호`가 더 잘 열림). 확인 못 한 내용은 "후기 기준"이라고 표시.
5. 아래 형식으로 정리.

## 답변 형식 (순서 고정)

```
## ✅ 공통 의견 TOP (N개 글에서 반복)
- 내용 — 🟢12 🟡3 (최근 3개월 12개 글, 3~12개월 3개 글) [대표 글 링크 1~2개]

## ⚠️ 필수로 알아야 할 정보 (모르면 손해)
- 🚫 [환불/취소] 알함브라 티켓 환불 불가 — 날짜·이름 오타도 변경 안 됨
- 🚗 [필수 선택] 렌트카는 자동변속기(오토) 지정 — 기본이 수동
- 🛡️ [필수 선택] 풀커버(무보험 면책) 보험 — 긁힘·휠 손상 청구 사례
- 💸 [과태료] 구시가지 통행제한구역 진입 → 몇 달 뒤 과태료 메일
(규칙: 돈이 나가거나, 되돌릴 수 없거나, 현장에서 해결 불가한 것만. 일반 상식·취향은 제외)

## 💡 알아두면 좋은 팁
- (공통은 아니지만 유용한 것, 소수 의견은 "일부 후기" 표시)

## 🕰️ 참고 / 주의
- 3~12개월 글에서만 나온 가격·운영시간·예약 방식은 "바뀌었을 수 있음" 표시
- 광고 의심 글 수, 카페 글은 날짜 확인 불가라는 점
```

정리 원칙:
- **최근 3개월 글이 우선**. 최근 글과 오래된 글이 다르면 최근 글을 따르고 차이를 적는다.
- 공통 의견은 **많이 나온 순**으로, 글 수를 숫자로 보여준다 (🟢/🟡 나눠서).
- 1개 글에만 나온 내용은 필수 정보로 올리지 않는다 (단, 환불불가·과태료처럼 피해가 큰 내용은 "일부 후기"로 표시해서 포함).
- 공식 정보로 꼭 다시 확인해야 할 것(가격, 규정)은 "공식 홈페이지 재확인" 표시.

## 오류 대처
- 네트워크 끊김은 자동으로 최대 4번 재시도한다. 그래도 실패하면 `naver-search` 스킬의 오류 대처를 따른다.
- 결과가 너무 적으면 `--must`를 줄이거나(예: `--must 알함브라`) 검색어를 바꾼다.
- 관련 없는 글이 많으면 `--must`에 단어를 추가한다.
