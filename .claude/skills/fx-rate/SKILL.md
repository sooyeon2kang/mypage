# 최신 환율 (Frankfurter · 유럽중앙은행 기준 · 키 불필요)

```bash
F=.claude/skills/fx-rate/scripts/fx.py
python3 $F rate                      # EUR·USD·JPY 최신
python3 $F rate EUR GBP
python3 $F convert 807 EUR           # 환산 + 카드결제 예상 범위
python3 $F compare --krw 1181259 --foreign 807 --cur EUR --cashback 20000
python3 $F trend EUR --days 30       # 최고/최저/평균/변화율 (--table 날짜별)
```

## 규칙
1. **환율 숫자는 이 스크립트 결과만 사용**. 웹 검색 결과·이전 대화의 환율을 재사용하지 않는다. 답변에 **기준일**을 꼭 적는다.
2. 기준: 유럽중앙은행 고시(영업일 하루 1번 갱신, 주말은 직전 영업일). 한국 은행 매매기준율과 약간 다를 수 있다고 한 줄 표시.
3. 카드 외화결제 = 기준환율 × (1 + 추가비용). 추가비용 기본 **1.4~2.4%** 범위로 보여준다
   (송금환율 가산 ~1% + 국제브랜드 ~1% + 카드사 ~0.2~0.3%). 사용자가 카드 수수료를 알려주면 `--fee`로 고정.
4. 원화 결제: 간편결제(네이버페이·카카오페이)·국내처리면 수수료 0, 카드 해외원화결제면 `--krw-fee 1.4` 정도.
5. 외화 카드결제 환율은 **매입일(승인 2~3일 뒤)** 에 확정, 환불은 환불 시점 환율 → 필요하면 한 줄 안내.
6. 사용자가 앱 화면 등으로 더 최신 환율을 주면 그 값을 우선하고, 스크립트 값과 차이를 함께 적는다.

## 오류
- 네트워크 오류 → 환경 허용 목록에 `api.frankfurter.dev` 필요.
- 실시간(분 단위)이 꼭 필요하면 사용자에게 알려주고, 한국수출입은행 API(무료 키, 전신환매도율 제공) 연동을 제안.
